# Test-only toolchain, pinned so a tool release cannot turn CI red on an
# unchanged commit (same reason as requirements-dev.txt).
#
# The SUITE itself is stdlib unittest; its one test-only dependency is the
# second entry below:
#
#   coverage — `coverage run -m unittest discover`, plus the
#   `--format=markdown` and `--fail-under` calls the workflow makes
#   directly, so the gate is a step of its own and the summary still
#   renders when it is red.
#
#   pytest — the timing harness speed.yml runs, and imported by
#   test_compare_durations.py, which tests that harness; the tests.yml
#   install step therefore needs it on every cell. It collects the
#   existing unittest TestCases unchanged and can emit --junitxml, which
#   stdlib unittest cannot. Nothing in the suite is WRITTEN against
#   pytest and nothing should be: `python3 -m unittest discover` stays
#   the way these tests are run.
coverage==7.16.1
pytest==9.1.1
