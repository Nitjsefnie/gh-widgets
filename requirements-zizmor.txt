# --require-hashes by the "Install zizmor" step in tests.yml's actionlint job.
# A version pin alone still installs whatever artifact the index serves for
# that version; these sha256 hashes make the install the same bytes on every
# run. PyYAML is a separately pinned toolchain package carried beside zizmor;
# it is used by the claim repo's YAML-consuming lint step, not required at
# runtime by zizmor. Its hash below covers the current CPython 3.13 x86_64
# manylinux wheel used by this workflow, not every artifact PyYAML publishes.
#
# Dependabot's pip entry (directory: "/" in .github/dependabot.yml) watches
# root requirements*.txt, so a bump arrives as a pull request rewriting the
# --hash lines beside it. If Dependabot cannot resolve the new version's
# hashes, it opens no pull request and the pin stays. The documented fallback
# is to regenerate by hand:
#
#   python3 -m pip download -d /tmp/req-dl zizmor==<new> PyYAML==<new>
#   sha256sum /tmp/req-dl/*
#
# then rewrite the --hash lines from that output.
